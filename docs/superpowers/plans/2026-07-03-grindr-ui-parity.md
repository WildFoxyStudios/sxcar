## Global Constraints
- **Tokens verbatim** (usar EXACTOS): kBg `#000000`, kSurface `#1A1A1A`, kChip `#2A2A2A`, kDivider `#333333`, kYellow `#FFCC00` (texto sobre amarillo SIEMPRE negro), kText `#FFFFFF`, kTextSecondary `#8E8E8E`, kTextTertiary `#666666`, kOnline `#1BD75E`, kBoost `#26D944`, kRightNow `#9B51E0`, kBadgeRed `#FF3B30`. Fuente Inter (google_fonts). Headers de sección: 13px CAPS letterspacing 1.2 color kTextSecondary.
- **Cero marcas Grindr** (ni máscara, ni "XTRA", ni "Grindr"): nombres de tiers desde backend; iconos Material.
- i18n: pantallas tocadas usan `AppLocalizations` (arb es+en). ES es la plantilla (textos de las capturas).
- Gates por tarea: `flutter analyze` 0; tests dirigidos nuevos + `flutter test` completo verde. `flutter build apk --debug` SOLO en T2 y T10. Backend: `cargo build -p api` + tests de integración con `DATABASE_URL=postgres://dev:dev@localhost:5433/appdb` (si Docker caído: arrancar Docker Desktop y `docker compose up -d postgres` en infra/).
- Riverpod 3 (sin `AsyncValue.valueOrNull`); `mounted` tras async; `await ref.read(authReadyProvider.future)` antes de fetch en initState.
- Commit directo a `main` (decisión del dueño), NO push (lo hace el controlador). Solo tocar los archivos del task. Reportes en `.superpowers/sdd/grindr-ui/task-N-report.md`.
