# Discover Feature — MVP Implementation

> **For agentic workers:** Use superpowers:subagent-driven-development.

**Goal:** Add a Discover section to the app with curated user profiles — extends the existing grid infrastructure with a different ranking algorithm. 100% Grindr parity for Discover.

**Architecture:** Backend `GET /discover` endpoint reuses the grid query but ranks by different criteria (activity + profile completeness instead of pure distance). Flutter app adds a Discover tab/section with a card-stack or horizontal scroll view.

**Tech Stack:** Rust (axum), Flutter (Dart).
