# P4 — Mass l10n Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the 11 screens flagged in audit P4-1 as having incomplete or missing l10n coverage — 3 screens with zero l10n (login, register, profile_screen) + 8 screens with significant gaps.

**Source:** `docs/superpowers/audits/2026-07-06-full-audit.md` — P4 finding 1.

## Global Constraints
- No git push. No secrets.
- Every user-facing string MUST go through `AppLocalizations.of(context)!.<key>`.
- ARB keys follow existing naming patterns (snake_case for English, camelCase for Spanish where existing code does so).
- Run `flutter gen-l10n` after every ARB change.
